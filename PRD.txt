# Multi-Tenant RBAC Application - Product Requirements Document

## 1. Project Overview

### 1.1 Project Summary
A comprehensive multi-tenant application with Role-Based Access Control (RBAC) supporting Angular, React, and React Native clients with a unified MySQL backend.

**Frontend Frameworks:**

## 3. Technical Implementation Details

### 3.1 Database Schema (MySQL + Prisma)

**Core Tables:**
```sql
-- Tenants
tenants (id, name, slug, domain, status, settings, created_at, updated_at)

-- Users (multi-tenant)
users (id, tenant_id, email, password, first_name, last_name, status, last_login, created_at, updated_at)

-- Roles
roles (id, tenant_id, name, description, permissions, is_default, created_at, updated_at)

-- User Roles (many-to-many)
user_roles (user_id, role_id, assigned_by, assigned_at)

-- Permissions
permissions (id, resource, action, description)

-- Role Permissions
role_permissions (role_id, permission_id)

-- Audit Logs
audit_logs (id, tenant_id, user_id, action, resource, old_values, new_values, ip_address, user_agent, created_at)

-- Sessions
sessions (id, user_id, token, refresh_token, expires_at, created_at)
```

### 3.3 Frontend Architecture

**React Implementation:**
```typescript
// Store Structure (Redux Toolkit)
interface RootState {
  auth: AuthState;
  tenant: TenantState;
  users: UsersState;
  roles: RolesState;
  ui: UIState;
  notifications: NotificationsState;
}

// RTK Query API Slices
const authApi = createApi({
  reducerPath: 'authApi',
  baseQuery: fetchBaseQuery({
    baseUrl: '/api/auth',
    prepareHeaders: (headers, { getState }) => {
      const token = (getState() as RootState).auth.token;
      if (token) headers.set('authorization', `Bearer ${token}`);
      return headers;
    },
  }),
  endpoints: (builder) => ({
    login: builder.mutation<LoginResponse, LoginRequest>({
      query: (credentials) => ({
        url: 'login',
        method: 'POST',
        body: credentials,
      }),
    }),
  }),
});
```
